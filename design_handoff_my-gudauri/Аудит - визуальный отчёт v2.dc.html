03 · P1

Легаси CSS всё ещё импортируется и переопределяется

HomePage делает import '../../../styles/design-1-home.css', хотя докумен­тация зовёт styles/ «легаси для справки». Дальше page-polish.scss переопределяет весь сервис-грид. Две полные раскладки дерутся, а Figma-координаты в пикселях всё ещё в проде (нарушение правила №2).

04 · P1

Нет единой ширины контента

Токен --content-width: 1468px есть, но на практике каждая страница берёт своё значение. Границы блоков не совпадают между разделами.

1468px .home-page (токен) 1600px .destination-page ← шире всех 1388px .site-nav-host / *-shell 1386px .service-grid
05 · P2

Внесистемные веса и сырые значения

Веса заданы в токенах (400/500/600/700), но всплывают произвольные и сырые числа вместо var(--fw-*). Плюс старый баг line-height живёт в мёртвом коде system.css.

.destination-promise strong { font-weight: 460 } ← вне шкалы .destination-eyebrow { font-weight: 600 } ← сырое, не var(--fw-semibold) .nav-links { line-height: 10px } (system.css) ← старый баг в мёртвом коде
06 · P2

system.css везёт второй, мёртвый словарь

Помимо актуальных .site-nav* и .ui-*, файл содержит целый набор классов, которые React не использует. Мёртвый код путает и раздувает легаси-слой.

.navbar · .brand · .nav-links · .hero-title · .hero-sub .card · .card-media · .footer · .footer-grid · .step · .shell
