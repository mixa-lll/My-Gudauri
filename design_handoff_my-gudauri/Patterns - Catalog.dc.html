Patterns / Catalog Секции мега-шаблона каталога Каждая секция — отдельный компонент. Утверждаем по одной, затем собираем каталоги категорий из instances. Мега-шаблон каталога и каталог инструкторов уже пересобраны из этих секций — внешне без изменений.
Missing components — нет в дизайн-системе
Прорисовать до сборки hi-fi, дубликаты не создавать: SiteNavbar · SiteFooter · CategoryTab · FilterControl (пилюля-дропдаун) · ResultCount · PromoBanner (контейнер-слот) · BenefitCard · BookingStep · MediaPlaceholder
Уже есть в дизайн-системе — реюз
Не перерисовывать, брать из бандла: Button · Pill · SectionHeading · Badge · ListingCard (+ Pill / Rating / Price) · InstructorCard · FaqAccordion · Container
Как читать
Пунктирное подчёркивание — текст, который задаёт шаблон-плейсхолдер. Серый чип — значение из БД. У каждой секции есть вариант mode="filled": чипы становятся голубыми (контент категории), как в каталоге инструкторов.

Catalog / PromoBanner CatalogPromoBanner.dc.html · слот
Назначение
Слот произвольного промо-контента категории (промо, условия, цены).
Анатомия
Контейнер-слот; наполнение — произвольная вёрстка. У инструкторов: «Персональный подбор» + полоса «Единая ставка».
Обязательно / опционально
Блок целиком опционален, 0–2 полосы.
Данные категории
Весь контент. Не зашивается в общую секцию — кастомная вёрстка живёт на странице категории, секция даёт только слот.
Варианты
placeholder (пунктир) / кастомная вёрстка per-категория.
Desktop / mobile
Desktop — полная ширина. Mobile — полосы складываются в столбец, CTA на всю ширину.
Кастомный баннер категории произвольная вёрстка и текст — заводится вручную для каждой категории · может быть 1–2 полосы (промо, условия, цены)
Catalog / CategoryTabs CatalogCategoryTabs.dc.html · внутри: CategoryTab ×N
Назначение
Первый уровень навигации по разделу — значения главного поля БД категории.
Анатомия
Подпись раздела · CategoryTab ×N (лейбл, подпись, счётчик), таб «Все» — первым.
Обязательно / опционально
Обязательны «Все» + ≥1 подкатегория и счётчики; подписи под лейблами опциональны.
Данные категории
Список табов и счётчики N из БД.
Варианты
CategoryTab: активный / неактивный; секция: template / filled.
Desktop / mobile
Desktop — одна строка. Mobile — горизонтальный скролл табов, подпись раздела сверху.

Catalog / FilterToolbar + ResultsHeader CatalogFilterToolbar.dc.html · внутри: FilterControl ×N, ResultCount
Назначение
Уточнение выборки внутри выбранного таба + счётчик результатов.
Анатомия
SectionHeading S · FilterControl (пилюля-дропдаун) ×N · ResultCount справа. ResultsHeader в текущем дизайне совмещён с тулбаром — отдельная секция не нужна.
Обязательно / опционально
Обязательны ≥1 фильтр и счётчик; кикер опционален.
Данные категории
Набор фильтров = поля БД категории; словоформа счётчика («8 инструкторов»).
Варианты
FilterControl: закрыт / открыт / активен (коралловый в hi-fi); секция: template / filled.
Desktop / mobile
Desktop — фильтры слева, счётчик справа. Mobile — кнопка «Фильтры» открывает шторку, счётчик под ней.

Catalog / ListingGrid CatalogListingGrid.dc.html · внутри: ListingCard ×N
Назначение
Результаты выборки — карточки объектов из БД.
Анатомия
ListingCard ×N: MediaPlaceholder + FilterChip-пилюли · название + Badge · ключевые теги · метрика (Rating или цена) · ссылка «Подробнее ↗».
Обязательно / опционально
Обязательны медиа, название, ссылка; бейдж, пилюли и метрика — опциональны.
Данные категории
Состав плашек — свой набор полей у каждой категории; число карточек из БД; клик → /:category/:slug.
Варианты
Карточка с рейтингом (инструкторы) / с ценой (прокат, туры); hover-lift; карточка реюзается в «Другие предложения» на странице объекта.
Desktop / mobile
Desktop — 4 колонки. Mobile — 1–2 колонки, подвал карточки не меняется.
