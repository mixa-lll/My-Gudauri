# Handoff: My Gudauri — дизайн → рабочий сайт (для Claude Code)

## Что это

Пакет передачи работы из дизайн-проекта в код. Внутри — все HTML-прототипы
My Gudauri, дизайн-система (токены + бандл компонентов) и два спека по
приведению репозитория в порядок.

**Целевой код:** `mixa-lll/My-Gudauri@main` (React + SCSS, деплой на Cloudflare
Pages, D1 + Pages Functions для бронирований инструкторов).

## Главное правило

Файлы `*.dc.html` в этом пакете — **дизайн-референсы, а не продакшн-код**.
Их нельзя копировать в репозиторий. Задача Claude Code — **воспроизвести эти
экраны средствами существующего стека репозитория**: React-компоненты в
`src/components/`, SCSS-токены в `src/styles/tokens/`, страницы в `src/pages/`.
Разметка внутри `.dc.html` использует собственный рантайм (`support.js`,
`<x-dc>`, `<sc-for>`) — берите из неё **структуру, размеры, цвета, копирайт и
поведение**, а не сам код.

## Порядок работы (рекомендую именно так)

1. **Сначала чистка, потом новые экраны.** Открыть
   `FIX-SPEC (English) - My-Gudauri design system.md` и пройти P0 → P3 по
   одному PR на группу. Пока в репозитории два конфликтующих набора токенов и
   две реализации страницы каталога, любой новый экран будет наследовать
   расхождение.
2. **Зафиксировать паттерны каталога и объекта** из `Patterns - Catalog.dc.html`
   и `Patterns - Object.dc.html` как единственные шаблоны для всех категорий
   (Instructors, Activities, Rental, Services, Real estate, Transfer, Tours, Places).
3. **Потом новые/переработанные экраны** — заявка (`Заявка - hi-fi поток`) и
   админка (`Админка - hi-fi редактор инструктора`).

```
Прочитай docs/design/README.md и FIX-SPEC (English) - My-Gudauri design system.md.
Работай по FIX-SPEC, группа P0, один PR. Не меняй ничего вне описанного в группе.

и токенах src/styles/tokens/*. Не копируй HTML из .dc.html в репозиторий.
В конце: покажи diff и прогони grep-чеклист из конца FIX-SPEC.
```

Дальше по одной задаче за раз: `«P0-2»`, `«P1-3»`, затем
`«реализуй экран из docs/design/Заявка - hi-fi поток.dc.html как src/pages/BookingFlowPage»`.

## Как положить пакет в репозиторий

```bash
git clone git@github.com:mixa-lll/My-Gudauri.git
cd My-Gudauri
mkdir -p docs/design
# распакованный zip → docs/design/
git checkout -b design/handoff && git add docs/design && git commit -m "docs: design handoff bundle"
```

Дальше `claude` в корне репозитория — Claude Code видит и код, и дизайн рядом.

## Как посмотреть дизайны глазами

Открыть любой `*.dc.html` двойным щелчком **из этой папки целиком** (нужны
`support.js`, `mg-proto.css`, `image-slot.js` и `_ds/` рядом). Файлы
интерактивные: клики, шаги заявки, аккордеоны работают.

## Дизайн-система: единственный источник правды по значениям

`_ds/my-gudauri-design-system-.../`

- `tokens/colors.css` — палитра. Нейтраль `--grey-50 #f6f6f3` → `--grey-800 #0e0f0d`;
  единственный насыщенный цвет — коралл `--rad-600 #df4b3f`; тинты секций
  `olive-50`, `blue-50`, `sand-50`; статусы `success-600`, `warning`, `danger-700`.
- `tokens/typography.css` — Geist (100–900) для всего UI; Paytone One только для
  display/wordmark. Заголовки: medium, tracking `-0.055em`. Кикер: 13px, 600,
  uppercase, `0.08em`. HUD-подписи: 12px, uppercase, `0.18em`.
- `tokens/spacing.css` — шкала 6→80px, `--content-width: 1468px`,
  `--layout-margin` 18–48px, вертикаль секций 48–88px.
- `tokens/effects.css` — радиусы `xsm 10` → `xl 36`; карточки 22–30px (внешний 28,
  медиа внутри 22); `--shadow-card: 0 18px 48px rgba(24,25,22,.06)`; `--shadow-float`;
  стекло `rgba(255,255,255,.86) + blur(9px)`.
- Моушн: 150/200/250ms, `cubic-bezier(0.2,0,0,1)`. Карточка hover: `translateY(-4px)`
  + тень, картинка `scale(1.035)` за 500ms. FAQ — через `grid-template-rows`.
  Никаких bounce и бесконечных циклов; `prefers-reduced-motion` уважается.
- Состояния: hover у outline-кнопки — заливка кораллом; ссылки → коралл;
  focus — `outline: 2px var(--grey-600)`, offset 3px; disabled — opacity 0.4–0.45.
- `_ds_bundle.js` — React-компоненты дизайн-системы (`Button`, `Pill`,
  `SectionHeading`, `Container`, `ListingCard`, `InstructorCard`, `DestinationCard`,
  `Stepper`, `IconButton`, `Field`/`Input`/`Textarea`/`Select`/`Checkbox`/`Radio`,
  `FaqAccordion`, `Badge`). В репозитории им соответствуют `src/components/UI/*` —
  сверяйте значения, а не подключайте бандл.

## Копирайт и тон

Английский UI, валюта `₾`. Второе лицо, без хайпа и эмодзи. Sentence case в
заголовках и кнопках. Статусы короткие и буквальные: «Available this week»,
«Limited availability», «Verified instructor», «2 hour lesson».

## Ассеты

Фото и иконки — из репозитория (`assets/navbar/`, `assets/design-2/`,
`assets/hero-gudauri.png`, `map-gudauri.jpg`). В прототипах местами стоят
плейсхолдеры (`image-slot.js`) — в продакшне подставлять реальные файлы из репо.
Иконки — растровые PNG для категорий/дисциплин и тонкие inline-SVG для хрома;
иконочного шрифта и эмодзи в проекте нет. Логотипа-символа нет — только
текстовый вордмарк «My Gudauri» (Paytone One, «My» в `grey-400`, «Gudauri» в `grey-600`).

## Что уже сделано в дизайн-проекте (не переделывать)

## Обратная связь в дизайн-проект

Когда PR влит — вернитесь в дизайн-проект и попросите синхронизацию: он читает
`github.md` (repo/branch/последний коммит + карта экранов) и подтянет изменения,
чтобы прототипы не разъехались с кодом.
