Patterns / Object Секции мега-шаблона страницы объекта Единая внутренняя страница для всех категорий — /:category/:slug. Тот же принцип, что и в Patterns / Catalog: каждая секция — отдельный компонент, утверждаем по одной, затем собираем страницы объектов из instances. Структура одинакова у инструктора, активности, тура; меняются только данные категории и 0–2 уникальных блока. Основа — вайрфрейм каталога инструкторов.
Missing components — нет в дизайн-системе
Прорисовать до сборки hi-fi, дубликаты не создавать: ObjectHero · MainTag · ReviewCard · BookingWidget · MediaPlaceholder
Уже есть — реюз (из ДС и из каталога)
Не перерисовывать: Button · Pill · SectionHeading · Badge · Stepper · Container. Общие с каталогом и описаны там — SiteNavbar · SiteFooter · BookingSteps; карточка ListingCard реюзится в «Других предложениях».
Как читать
Пунктирное подчёркивание — текст шаблона-плейсхолдера. Серый чип — значение из БД объекта. Пунктирная рамка-поле — вводные пользователя, уходят в заявку. У каждой секции есть вариант mode="filled" с реальным контентом категории.
Object / Hero ObjectHero.dc.html · 2 раскладки
Назначение
Шапка объекта — кто/что это, ключевой факт, медиа и вход в галерею.
Анатомия
«← назад в каталог» · теги главного поля + тип · H1 название · ★ рейтинг + N отзывов · короткое интро · MediaPlaceholder со статусом и «Галерея · N фото».
Обязательно / опционально
Обязательны название и медиа; рейтинг, интро и бейдж — опциональны.
Данные категории
Название, медиа, рейтинг, интро — из БД объекта; ярлык типа — из категории.
Варианты
Две раскладки одного набора данных — A · сплит (текст + медиа) и B · по центру; выбор за категорией. + template / filled.
Desktop / mobile
Mobile — медиа сверху, текст под ним, H1 32–36px (обе раскладки).
AСплит — текст + медиаинструктор, прокат, жильё

Object / Reviews ObjectReviews.dc.html · внутри: ReviewCard ×N + ReviewsModal
Назначение
Социальное доказательство — отзывы гостей именно этого объекта.
Анатомия
На странице: SectionHeading S · ReviewCard ×2–4 · кнопка «Все отзывы (N)». По клику — отдельный попап ReviewsModal со скроллом всей ленты (без разбивки по категориям и «упоминается в отзывах»).
Обязательно / опционально
Блок опционален (если есть ≥1 отзыв); на странице 2–4, остальные — в попапе.
Данные категории
Все отзывы из БД, связанные с объектом; только от подтверждённых бронирований.
Кто может оставить
Отзыв доступен только после завершённого занятия / полученной услуги — гостю без подтверждённой брони кнопка не показывается.
Варианты
Секция на странице / попап (раскрыто); ReviewCard: подтверждён / без метки.
Desktop / mobile
Desktop — попап по центру. Mobile — попап на весь экран, лента скроллится.

Object / ReviewsModal
Назначение
Отдельный попап «Все отзывы» — открывается поверх страницы по кнопке.
Анатомия
Затемнение фона · карта по центру: шапка (заголовок + ×) · скроллируемая лента ReviewCard во всю ширину · футер с кнопкой «Оставить отзыв».
Упрощение
Без разбивки оценок по категориям, без блока «упоминается в отзывах» и без фильтров — только лента.
Оставить отзыв
Кнопка доступна только после завершённого занятия / полученной услуги; иначе — не показывается.
Desktop / mobile
Desktop — карта по центру, скролл внутри. Mobile — на весь экран.

Object / BookingWidget · sticky BookingWidget.dc.html · внутри: Stepper ×N, Field ×N, Button
Назначение
Ключевой конверсионный блок — цена, первичные вводные и старт заявки.
Анатомия
Цена / ставка · вводные категории (Stepper / поля: дата, часы, человек, уровень…) · Имя · Телефон · Комментарий · «Итого — расчёт» · Button «Продолжить».
Обязательно / опционально
Обязательны цена, ≥1 вводное, контакт и CTA; комментарий опционален.
Данные категории
Набор вводных полей и формула итога — свои у категории; ставка из БД объекта. Та же формула, что в карточке и каталоге.
Варианты
template / filled. Появляется в hero и остаётся закреплённым при скролле; первичные вводные уходят в заявку.
Desktop / mobile
Desktop — sticky в правой колонке. Mobile — закреплённая нижняя панель «от цены · Продолжить», раскрывается в лист.
подпись цены — категория цена / ставка
вводные категории — 2–4 поля (дата, часы, человек, уровень…) Имя Телефон / мессенджер Комментарий
Итого — расчёт формула своя у категории

Object / Блоки категории наполняют слот «Уникальные блоки категории» (0–2 шт.) · встают между «Доп. теги» и «Отзывы»
Назначение
Секции, которые есть только у отдельных категорий — вставляются в общий слот на своём месте.
Правило
Не общий компонент — вёрстка и поля БД живут на шаблоне категории. Максимум 2 блока на страницу.
Цвет
инструктор · активность
Дальше
