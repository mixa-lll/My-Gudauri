My Gudauri Структура страниц и данных по категориям

Каждая колонка — категория: сверху БД, ниже каталог и страница объекта. Порядок блоков — сверху вниз (↓), состав блока показан внутри него. Цвет блока = чья вёрстка, цвет плашки = откуда данные. Акцентный цвет столбца = категория: синий — инструкторы, зелёный — активности.
Типы блоков
шаблонный блок — вёрстка общая для всех категорий, наполнение из БД
одинаковый у всей категории (в цвете категории)
одинаковый на всех категориях сайта
уникальный блок — есть только у этой категории
Данные внутри блоков
общие на всю категорию конкретного объекта из БД первичные вводные при отправке заявки
Чтение схемы
↓ — порядок блоков на странице
→ — переход между страницами
